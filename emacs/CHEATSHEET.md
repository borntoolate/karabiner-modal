# キー割り当て早見表（Emacs 版）

**Caps Lock = Emacs の Control**、**Caps Lock + Shift = Emacs の Meta** です。
表記は Emacs の慣習に合わせて `C-f` = `Caps + f`、`M-f` = `Caps + ⇧ + f` と読んでください。

US（ANSI）配列前提。

---

## リーダーキーそのもの

| 操作 | 動作 |
|---|---|
| Caps Lock を単独で叩く | 何も起きない |
| Caps Lock を押しっぱなし | Emacs モード（`C-`）に入る |
| Caps Lock + Shift | Meta（`M-`） |

Caps Lock 本来の英大文字ロックは無効になります。

---

## 移動

| Emacs | 押すキー | 動作 |
|---|---|---|
| `C-f` | `Caps + f` | 1文字進む |
| `C-b` | `Caps + b` | 1文字戻る |
| `C-n` | `Caps + n` | 1行下 |
| `C-p` | `Caps + p` | 1行上 |
| `C-a` | `Caps + a` | 行頭へ |
| `C-e` | `Caps + e` | 行末へ |
| `C-v` | `Caps + v` | 1画面下へ |
| `M-f` | `Caps + ⇧f` | 1単語進む |
| `M-b` | `Caps + ⇧b` | 1単語戻る |
| `M-v` | `Caps + ⇧v` | 1画面上へ |
| `M-a` | `Caps + ⇧a` | 段落の先頭へ |
| `M-e` | `Caps + ⇧e` | 段落の末尾へ |
| `M-<` | `Caps + ⇧,` | 文書の先頭へ |
| `M->` | `Caps + ⇧.` | 文書の末尾へ |

`M-<` `M->` はキートップの `<` `>` の刻印がそのまま目印になります。

---

## アプリのショートカットを fbnp で押す

移動キー `f` `b` `n` `p` に ⌥ か ⌘ を足すと、**そのまま矢印キーに渡ります。**
矢印キーを使うアプリ側のショートカットを、ホームポジションから押せます。

| 押すキー | 送られるキー | 例 |
|---|---|---|
| `⌥` + `fbnp` | ⌥ + 矢印 | VS Code: `⌥↑` `⌥↓` で行を上下に移動 |
| `⌥⇧` + `fbnp` | ⌥⇧ + 矢印 | VS Code: `⌥⇧↑` `⌥⇧↓` で**行を複製** |
| `⌘` + `fbnp` | ⌘ + 矢印 | 文書の先頭・末尾へ、行頭・行末へ |
| `⌘⇧` + `fbnp` | ⌘⇧ + 矢印 | 選択しながら同上 |

たとえば VS Code の行複製は `Caps + ⌥ + ⇧ + n` です。

**素の Shift は渡りません。** この設定では Shift は Meta なので、`⇧f` は `M-f` です。

`gen.py` の `META_MOD` を `"option"` に変えた場合、⌥ は Meta になるため
**⌥ の行は生成されません**（⌘ の行は残ります）。

## 選択（マーク）

Emacs は Shift で選択しません。**マークを置いてから移動する**と、
その間が選択範囲になります。

| Emacs | 押すキー | 動作 |
|---|---|---|
| `M-SPC` | `Caps + ⇧Space` | マークを置く / 外す |
| `C-g` | `Caps + g` | マークを外して選択解除（Esc） |
| `C-w` | `Caps + w` | 選択範囲を切り取り |
| `M-w` | `Caps + ⇧w` | 選択範囲をコピー |
| `C-y` | `Caps + y` | 貼り付け |

マークを置いたあとは、**上の移動キーすべてが選択になります。**
`C-f` でも `M-f` でも `M->` でも同じです。Caps Lock を離すとマークは自動的に外れます。

### マウスで選択した続きから伸ばす

マウスで範囲を選んだあとに `Caps + ⇧Space` でマークを置き、そのまま移動キーを押すと
**アプリ側が持っている選択範囲の続きから伸びます。** Karabiner がマーク位置を
覚えているわけではないので、既存の選択とうまく噛み合います。

ただし読み取り専用のページで**選択が何もない状態**では、キャレットが存在しないため
移動キーは選択ではなくスクロールになります。

## 編集

| Emacs | 押すキー | 動作 |
|---|---|---|
| `C-d` | `Caps + d` | 1文字削除（前方 / Delete） |
| `C-h` | `Caps + h` | 1文字削除（後方 / Backspace） |
| `M-d` | `Caps + ⇧d` | 単語を前方に削除 |
| `M-DEL` | `Caps + ⇧Delete` | 単語を後方に削除 |
| `C-k` | `Caps + k` | カーソル位置から行末まで削除 |
| `C-o` | `Caps + o` | カーソル位置に空行を挿入 |
| `C-j` `C-m` | `Caps + j` / `Caps + m` | 改行 |
| `C-i` | `Caps + i` | Tab |
| `C-/` | `Caps + /` | 取り消し（Undo） |
| `C-s` | `Caps + s` | 検索（⌘F） |
| `C-r` | `Caps + r` | 前を検索（⌘⇧G） |

`C-k` `C-w` `M-w` `M-d` `M-DEL` はすべて **システムのクリップボード**を経由します。
本家 Emacs の kill ring とは違い、`C-y` で貼り付けられるのは直前の1つだけです。
その代わり、アプリをまたいで貼り付けられます。

## C-x プレフィックス

`Caps + x` を押してから、**0.8 秒以内**に次のキーを押します。
Caps Lock は押したままで構いません。

| Emacs | 押すキー | 動作 |
|---|---|---|
| `C-x C-s` | `Caps + x` → `s` | 保存（⌘S） |
| `C-x C-f` | `Caps + x` → `f` | ファイルを開く（⌘O） |
| `C-x C-w` | `Caps + x` → `w` | 別名で保存（⌘⇧S） |
| `C-x C-c` | `Caps + x` → `c` | **アプリを終了（⌘Q）** |
| `C-x k` | `Caps + x` → `k` | ウインドウ / タブを閉じる（⌘W） |
| `C-x h` | `Caps + x` → `h` | 全選択（⌘A） |
| `C-x u` | `Caps + x` → `u` | 取り消し（⌘Z） |
| `C-x o` | `Caps + x` → `o` | 次のウインドウへ（⌘`） |

**`C-x C-c` はアプリが終了します。** 誤爆が怖い場合は `gen.py` の
`X_COMMANDS` から該当行を消して再生成してください。

時間切れになると何も起きずに解除されます。`C-g` でも解除できます。

## 入力ソース切り替え

| 押すキー | 動作 |
|---|---|
| `Caps + Space` | 英語入力 / 日本語入力の切り替え（⌃Space） |

Vim 版と同じです。本家 Emacs の `C-SPC` は set-mark ですが、
毎日使う入力切り替えを優先して、マークは `Caps + ⇧Space` に置いています。

## 実装していないもの

| Emacs | 理由 |
|---|---|
| `C-l`（recenter） | 「カーソルを画面中央にスクロール」する手段が macOS にない |
| `C-t`（transpose-chars） | 文字の入れ替えを汎用的に行う方法がない |
| `M-y`（yank-pop） | kill ring がなく、クリップボードは1つだけ |
| `C-u`（universal argument） | 数引数の概念を持ち込めない |
| `C-x C-x`（point と mark の交換） | マークが実体を持たないため |
| `C-x 2` `C-x 3`（ウインドウ分割） | OS レベルの相当機能がない |

詳しくは `DESIGN.md` を参照してください。
