# キー割り当て早見表（Vim 版）

すべて **Caps Lock を押しながら**操作します。
`⇧` は Caps Lock と一緒に Shift、`⌃` は Caps Lock と一緒に Control を押す意味です。

**Shift は選択ではありません。** Vim の記法どおりの大文字・記号を表します
（`⇧4` = `$`、`⇧g` = `G`）。選択はビジュアルモード（`v`）で行います。

US（ANSI）配列前提。

---

## リーダーキーそのもの

| 操作 | 動作 |
|---|---|
| Caps Lock を単独で叩く | 何も起きない |
| Caps Lock を押しっぱなし | Vim モードに入る（離すと自動で抜ける） |

Caps Lock 本来の英大文字ロックは無効になります。

---

## 移動

| キー | Vim | 動作 |
|---|---|---|
| `h` `j` `k` `l` | | ← ↓ ↑ → |
| `w` / `⇧w` † | `w` `W` | 次の単語へ |
| `e` / `⇧e` † | `e` `E` | 単語の末尾へ |
| `b` / `⇧b` † | `b` `B` | 前の単語へ |
| `0` | `0` | 本当の行頭へ |
| `6` ‡ / `⇧6` | `^` | 行頭へ |
| `4` ‡ / `⇧4` | `$` | 行末へ |
| `9` ‡ / `⇧9` | `(` | 前の文（段落）へ |
| `⇧0` | `)` | 次の文（段落）へ |
| `⇧[` / `⇧]` | `{` `}` | 前 / 次の段落へ |
| `g` `g` | `gg` | 文書の先頭へ |
| `⇧g` | `G` | 文書の末尾へ |
| `⌃f` / `⌃b` | `C-f` `C-b` | 1画面 下 / 上へ |
| `⌃d` / `⌃u` | `C-d` `C-u` | 半画面 下 / 上へ |

### 凡例

この2つの記号はこの早見表全体で使います。**記号は直前のキーに掛かります。**

| 記号 | 意味 |
|---|---|
| † | 大文字は Vim では別コマンド（WORD 単位）。macOS に区別がないため小文字と同じ動作 |
| ‡ | Vim にはない追加、または Vim と意味を変えてある箇所。記号は**直前のキー**に掛かる |

**† 大文字は Vim では別のコマンドですが、ここでは小文字と同じ動作です。**
Vim の `W` `E` `B` は「WORD 単位」（空白だけで区切る）で、`foo.bar` を1つの塊として
飛び越えます。macOS の ⌥→ には word / WORD の区別がないため再現できません。
どちらを押しても同じ動作になる、という意味で併記しています。

**‡ そのキーは Vim にないか、Vim とは意味が違います。**
`^` `$` `(` は Vim では必ず Shift を伴いますが、行末移動などは頻繁に使うので
`Caps + 4` でも同じ動作にしてあります（`⇧4` の方が Vim 本来の打ち方です）。
回数指定（`6j` など）は実装していないので、数字キーは空いています。
意味を変えてあるのはビジュアルモードの `x` だけです（下記）。

## アプリのショートカットを hjkl で押す

`hjkl` に ⌥ か ⌘ を足すと、**そのまま矢印キーに渡ります。**
矢印キーを使うアプリ側のショートカットを、ホームポジションから押せます。

| 押すキー | 送られるキー | 例 |
|---|---|---|
| `⌥` + `hjkl` | ⌥ + 矢印 | VS Code: `⌥↑` `⌥↓` で行を上下に移動 |
| `⌥⇧` + `hjkl` | ⌥⇧ + 矢印 | VS Code: `⌥⇧↑` `⌥⇧↓` で**行を複製** |
| `⌘` + `hjkl` | ⌘ + 矢印 | 文書の先頭・末尾へ、行頭・行末へ |
| `⌘⇧` + `hjkl` | ⌘⇧ + 矢印 | 選択しながら同上 |

たとえば VS Code の行複製は `Caps + ⌥ + ⇧ + j` です。

**素の Shift は渡りません。** この設定では Shift は Vim の大文字を表すので
（`⇧j` は `J` = 行の連結）、`⇧j` は矢印になりません。

**Control も渡りません。** 渡す先は矢印キーですが、macOS で `⌃↑` `⌃↓` は
Mission Control と App Exposé であって、テキストの移動ではないためです。
Mission Control は素のカーソルキーで呼んでください。

## 定義していない組み合わせは何も起きない

Caps Lock を押している間、**この早見表にない `⌃` と `⌥` の組み合わせはすべて無反応です。**

| 押すもの | 結果 |
|---|---|
| 表にある `⌃` `⌥` の組み合わせ | 表のとおり |
| 表にない `⌃` `⌥` の組み合わせ | 何も起きない |
| `⌘` を含む組み合わせ | アプリにそのまま届く（`Caps + ⌘ + s` で保存できます） |

そのまま素通りさせると、macOS 側のキーバインドが顔を出します。`⌃` は macOS の
テキスト編集コマンド（`⌃k` で行末まで削除、`⌃a` で行頭へ、`⌃v` で1ページ下）、
`⌥` は文字入力（`⌥s` で ß、`⌥e` はアクセントを予約して**次の一打を食う**）です。
どちらも Vim とは別の体系で、`⌃v` のように同じキーで意味が食い違うものもあります
（Vim では矩形ビジュアル、macOS では1ページ下）。

Caps Lock を離せば `⌃k` も `⌥e` も通常どおり使えます。無効になるのは
Caps Lock を押している間だけです。

## 選択（ビジュアルモード）

| キー | Vim | 動作 |
|---|---|---|
| `v` | `v` | ビジュアルモードの開始 / 終了 |
| `⇧v` | `V` | 行単位のビジュアルモード（現在行を選択して開始） |
| `Esc` | | ビジュアルモードを抜ける |

ビジュアルモード中は、**上の移動キーがすべて「選択しながらの移動」になります。**
`⌃f` でも `⇧g` でも `⇧4` でも同じです。

**`⇧v`（`V`）の選択には改行が含まれます。** 画面上は次の行の先頭までハイライトされますが、
入っているのは改行1文字だけで、次の行の中身は入っていません。Vim の行単位選択も同じく
行の終端を含むので（`V` `y` した行が `p` で1行として貼り付くのはこのため）、
挙動は Vim どおりです。表示が違うのは、macOS の選択が文字単位しかなく
「行単位」という状態を持てないためです。

選択したあとの操作。実行するとビジュアルモードを抜けます。

| キー | Vim | 動作 |
|---|---|---|
| `y` | `y` | 選択範囲をコピー |
| `d` / `c` | `d` `c` | 選択範囲を切り取り（**クリップボードに入る**） |
| `x` ‡ | `x` | 選択範囲を削除（**クリップボードを汚さない**） |
| `p` | `p` | 選択範囲を貼り付けで置換（クリップボードは保たれる） |

Caps Lock を離すとビジュアルモードは自動的に解除されます。

**`x` だけ Vim と意味が違います。** Vim では `x` は `d` と同じで、消したものは
レジスタに残ります。macOS にはレジスタがなくクリップボードしかないため、
ここでは役割を分けてあります。消したものを `p` で貼り戻したいなら `d`、
コピー済みの内容を守りたいなら `x` です。

コピーしておいた文字列で既存の記述を差し替えるだけなら、`p` が最短です。
選択したところに貼り付けて置換するので、クリップボードは減りません。

```
（貼り付け元をコピー）→ 貼り付け先を v で選択 → p
```

先に消しておきたいときは `x`。`d` で消すとクリップボードが上書きされ、
貼り付けるはずだった内容が失われます。

### マウスで選択した続きから伸ばす

マウスで範囲を選んだあとに `Caps + v` でビジュアルモードに入り、移動キーを押すと
**アプリ側が持っている選択範囲の続きから伸びます。**

ただし読み取り専用のページで選択が何もない状態では、キャレットが存在しないため
移動キーは選択ではなくスクロールになります。

## 編集

| キー | Vim | 動作 |
|---|---|---|
| `x` | `x` | 1文字削除（前方 / Delete） |
| `⇧x` | `X` | 1文字削除（後方 / Backspace） |
| `⇧d` | `D` | カーソル位置から行末まで削除 |
| `d` `d` | `dd` | 行を切り取り（改行含む） |
| `y` `y` / `⇧y` | `yy` `Y` | 行をコピー |
| `p` / `⇧p` | `p` `P` | 貼り付け |
| `⇧j` | `J` | 次の行と連結 |
| `o` | `o` | 下に空行を開く |
| `⇧o` | `O` | 上に空行を開く |
| `u` | `u` | 取り消し（Undo） |
| `⌃r` / `⇧u` ‡ | `C-r` | やり直し（Redo） |
| `a` ‡ | | 全選択（⌘A） |

2連打は **0.8 秒以内**に押してください。時間切れになると何も起きずに解除されます
（Vim と同じく、`d` 単独では何も削除しません）。

`d` `d` は**クリップボードに入ります**（`p` で貼り戻せます）。
`⇧d`（`D`）は選択して Delete しているだけなので、クリップボードを汚しません。

**クリップボードを汚さずに1行消す**には `⇧v` → `x`（行を選択してから削除）。

## 検索

| キー | Vim | 動作 |
|---|---|---|
| `/` / `?` | `/` `?` | 検索（⌘F） |
| `n` | `n` | 次の一致へ（⌘G） |
| `⇧n` | `N` | 前の一致へ（⌘⇧G） |

macOS には後方検索がないので、`?` は `/` と同じく検索バーを開きます。

---

## ex コマンド（`:`）

`Caps + ⇧;`（`:`）を押してから、**0.8 秒以内**に次のキーを押します。

| キー | Vim | 動作 |
|---|---|---|
| `:` → `w` | `:w` | 保存（⌘S） |
| `:` → `q` | `:q` | ウインドウ / タブを閉じる（⌘W） |
| `:` → `x` | `:x` | 保存して閉じる（⌘S → ⌘W） |

`Esc` でも解除できます。

## 入力ソース切り替え

| キー | 動作 |
|---|---|
| `Space` | 英語入力 / 日本語入力の切り替え（⌃Space） |

`Caps + Space` という指の動きは、Caps Lock を Control にリマップしていた頃と同じです。
詳しくは `../docs/CONTROL-KEY.md` を参照してください。

## 実装していないもの

| Vim | 理由 |
|---|---|
| `%`（対応するかっこへ） | macOS のテキストシステムに括弧ジャンプ機能がない |
| `H` `L` `M`（画面の先頭・末尾・中央へ） | 「可視領域の先頭行」を指すコマンドが macOS にない |
| `f` `t`（行内の文字へジャンプ） | 検索対象の文字を Karabiner が受け取れない |
| `.`（直前の操作を繰り返す） | 操作履歴の概念がない |
| `m` `'`（マーク） | 位置を記憶する手段がない |
| `~` `gu` `gU`（大文字小文字の変換） | 相当機能がない |
| `>>` `<<`（インデント） | ⌘] / ⌘[ はエディタ限定で、ブラウザでは別の意味になる |

詳しくは `LIMITATIONS.md` を参照してください。
