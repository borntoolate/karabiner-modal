# 制約と、実装を見送ったもの

要望のうち実装できなかったもの、および仕様どおりには動かない部分の説明です。
「なぜできないのか」まで書いておくので、代替案の判断材料にしてください。

---

## 実装できなかったもの

### `%` — 対応するかっこへ移動

**できません。**

macOS のテキスト編集はほぼすべて Cocoa（AppKit）の共通処理を通っており、
カーソル移動は `moveToEndOfLine:` のような**セレクタ**という単位で提供されています。
Karabiner ができるのは「このセレクタを呼ぶキーストロークを送る」ことだけです。

そして Cocoa には**「対応する括弧へジャンプする」セレクタが存在しません。**
括弧の対応を取るには構文を解析する必要があり、それは OS の仕事ではなく
エディタの仕事だからです。

**代替案**：括弧ジャンプが必要な場面はほぼコード編集中のはずなので、
エディタ側の機能を使うのが確実です。

| エディタ | 標準の割り当て |
|---|---|
| VS Code | `⌘⇧\` (Go to Bracket) |
| JetBrains 系 | `⌃M` (Move Caret to Matching Brace) |
| Xcode | ダブルクリックで括弧の中身を選択 |
| Vim / Neovim | `%`（本家） |

### `H` / `L` — 画面の先頭・末尾へ移動

**見送りました。**

Vim の `H` / `L` は「今スクロールして見えている範囲の、一番上／一番下の行」に
カーソルを移す操作です。**文書基準ではなく画面（ビューポート）基準**なのが特徴で、
`gg` / `G` とはここが違います。

| | 基準 | 動作 |
|---|---|---|
| `gg` / `G` | 文書全体 | ファイルの先頭行 / 最終行へ。大きくスクロールする |
| `H` / `L` | 見えている画面 | スクロールせず、可視範囲の上端 / 下端にカーソルだけ移す |

Cocoa には**「可視領域の先頭行にカーソルを移動する」セレクタがありません。**
近いのは Page Up / Page Down ですが、こちらは挙動がアプリによってばらばらです。

- テキストエディタ系：スクロールし、カーソルも一緒に動く
- Safari など閲覧系：スクロールするだけでカーソルは動かない
- `scrollPageUp:` と `pageUp:` を使い分けるアプリもあり、統一されていない

「アプリによって動いたり動かなかったりする」割り当ては、ないほうがマシと判断しました。

**画面単位のスクロールは別途あります。** Vim 本来の `C-f` / `C-b`（1画面）と
`C-d` / `C-u`（半画面）を `Caps + ⌃f` などに割り当ててあるので、
「大きく動く」用途はこちらで足ります。macOS には半画面スクロールがないため、
`C-d` / `C-u` も 1画面分になります。

**もし `H` / `L` が必要なら**：`gen.py` の `MOVES` に以下を足してください。
`⇧h` / `⇧l` は現在使っていないので空いています。

```python
("h", "shift", "page_up",   [], "H: page up (approximation)"),
("l", "shift", "page_down", [], "L: page down (approximation)"),
```

## 仕様どおりには動かない部分

### `^` と `0` が同じ動作になる

Vim では区別があります。

- `0` — 本当の行頭（インデントの空白より手前）
- `^` — 行頭の最初の非空白文字

macOS の ⌘← はこの区別を提供していません。どちらか一方の挙動しかなく、
しかもアプリによってどちらかが違います。

- **VS Code / JetBrains 系** — ⌘← が「非空白文字 → 行頭」をトグルする実装。
  結果的に `^` と `0` の両方が使えます（2回押せば行頭）
- **その他の多くのアプリ** — ⌘← は常に本当の行頭

そのため `0` と `6`（`^`）の両方を ⌘← に割り当てています。
アプリが賢ければ賢いなりに、そうでなければ「常に行頭」として振る舞います。

---

### `(` `)` は「文」ではなく「段落」単位

Vim の `(` `)` は文（sentence）単位、つまり `.` `!` `?` で区切られた単位で移動します。
macOS には**文単位のカーソル移動が存在しません。** 段落（paragraph）単位が最小です。

そこで ⌥↑ / ⌥↓（`moveToBeginningOfParagraph:` / `moveToEndOfParagraph:`）に
割り当てています。1行が1段落の文書（コードなど）では、実質「行頭 / 行末へ」の動作です。

**結果として `(` `)` と `{` `}` が同じ動作になります。** Vim では前者が文単位、
後者が段落単位ですが、macOS 側に区別がないため両方とも段落移動です。
どちらの指の形でも押せるように、あえて両方残してあります。

---

### `w` と `W`、`e` と `E`、`b` と `B` の区別がない

Vim の小文字は「単語」、大文字は「WORD（空白区切りの塊）」です。
macOS の ⌥→ / ⌥← にこの区別はないため、**大文字と小文字を同じ動作**にしてあります。

区別が失われる代わりに、Shift を押していても押していなくても同じ結果になるので、
指がもたついたときに変な動きをしません。

---

### `yy` の後のカーソル位置

Vim の `yy` はヤンク後もカーソルが元の桁位置に留まります。

この設定では「行頭へ → 次の行頭まで選択 → ⌘C → ←」という手順を踏むため、
**実行後のカーソルは行頭に移動します。** 元の桁位置は復元できません
（macOS 側に「カーソル位置を記憶して戻る」手段がないため）。

---

### `dd` を最終行で実行したとき

`dd` は「行頭へ → ⇧↓ で次の行頭まで選択 → ⌘X」で実装しています。
最終行に改行がない場合、⇧↓ は行末までしか選択できないため、
**空行が1行残ります。** Vim なら行ごと消えるところです。

気になる場合は `dd` の後に `⇧x`（Backspace）を1回足してください。

---

### `d` を武装したまま `⇧d` を押すと

`d` を1回押して 800ms 以内に `⇧d` を押すと、どちらのルールにもマッチせず
**`D` の文字が入力されます。**

`dd`（`vim_d == 1` で Shift なし）にも `D`（`vim_d != 1` で Shift あり）にも
当てはまらない隙間です。押し間違えたときにだけ起きる稀なケースなので、
特別扱いはしていません。Caps Lock を離せば状態はリセットされます。

`y` → `⇧y`、`g` → `⇧g` も同様の隙間がありますが、こちらは
`Y` と `G` のルールに `vim_y != 1` / `vim_g != 1` の条件を付けていないため、
2打目として素直に解釈されます（`g` → `⇧g` は「文書の末尾へ」になります）。

---

### `O`（上に空行）が空白行の直後で崩れる

`O` は「⌘← で行頭へ → Enter → ↑」で実装しています。
ソフトラップされた長い行では、⌘← が視覚上の行頭に止まるアプリがあり、
その場合は意図した位置に空行が入りません。

---

### `:x`（保存して閉じる）の順序

`⌘S` → `⌘W` を続けて送っています。保存に時間がかかるアプリでは、
保存が完了する前に閉じようとして確認ダイアログが出ることがあります。
確実に行きたい場合は `:w` と `:q` を分けて実行してください。

---

## 動作しない環境

macOS のテキスト入力はほぼすべて Cocoa を通るため、この設定は
Safari、Mail、Xcode、Slack、Notion、ターミナルなど大半のアプリで同じように動きます。

一方、以下では期待どおりに動かないことがあります。

| 環境 | 理由 |
|---|---|
| リモートデスクトップ / VNC / 仮想マシン | キー入力が転送先に丸投げされ、⌘← などの意味が変わる |
| 一部の Java 製アプリ | 独自のテキスト実装で Cocoa のキーバインドに従わない |
| ゲーム、独自 UI のアプリ | キー入力を生で読んでいる |
| Vim / Emacs 本体 | そもそも自前のキーバインドがある。**Karabiner 側で除外するのが吉** |

最後の項目は実用上けっこう効きます。Vim や Emacs の中では
この設定が邪魔になるので、除外条件を足しておくと快適です。
`gen.py` の `VM` を書き換えて、全ルールに以下を追加してください。

```python
NOT_TERMINAL = {
    "type": "frontmost_application_unless",
    "bundle_identifiers": [
        "^com\\.apple\\.Terminal$",
        "^com\\.googlecode\\.iterm2$",
        "^dev\\.warp\\.Warp-Stable$",
    ],
}
```

アプリのバンドル ID は Karabiner-EventViewer の
**Frontmost Application** タブで調べられます。
